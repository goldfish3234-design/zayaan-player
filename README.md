# ZAYAAN

Android video player app (Flutter).

## Features
- Pick one or many videos from the phone
- Playlist with auto-play of the next video
- Play / pause, seek bar, skip 10s back / forward
- Double tap left or right side of the screen to skip 10s
- Playback speed (0.5x to 2x)
- Landscape / portrait toggle, full screen playback

## Build APK
Push to `main` and GitHub Actions builds the APK automatically.
Open the Actions tab, open the latest run, download the `zayaan-apk` artifact.
